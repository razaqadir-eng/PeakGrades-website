Surds and Indices.

GCSE Higher (Grades 6-9)board-neutral (AQA / Edexcel / OCR)Worksheet: 25 marks

NotesWorksheet

Notes

Key idea

A surd is an irrational root left in exact form, such as √2 or 3√5. Exact answers keep the surd; a decimal is only an approximation.

Surd rules

  • √a × √b = √(ab)
  • √a ÷ √b = √(a/b)
  • (√a)² = a
  • To simplify, pull out the largest square factor: √72 = √(36 × 2) = 6√2
  • Only "like" surds add or subtract: 3√2 + 5√2 = 8√2, but √2 + √3 cannot be combined.

Rationalising the denominator

  • Single surd: multiply top and bottom by the surd. 6/√3 = 6√3/3 = 2√3
  • Binomial: multiply top and bottom by the conjugate (change the sign between the terms).
    1/(3 + √2) = (3 − √2) / ((3 + √2)(3 − √2)) = (3 − √2)/7
  • Useful identity: (a + √b)(a − √b) = a² − b, so the surd always disappears.

Worked examples

  1. Evaluate 8^(−2/3). Root first, then power, then reciprocal: ∛8 = 2, 2² = 4, so the answer is 1/4.
  2. Expand (2 + √3)² = 4 + 4√3 + 3 = 7 + 4√3.
  3. Solve 9^x = 27. Write both as powers of 3: 3^(2x) = 3³, so 2x = 3 and x = 3/2.

Common mistakes

  • Writing √(a + b) = √a + √b. This is false.
  • Forgetting that a negative power means a reciprocal, not a negative number.
  • Rationalising with the wrong sign in the conjugate.
  • Leaving a surd in the denominator of a final answer.

Exam tips

  • "Show that" and "exact value" questions need surd or fraction answers, never decimals.
  • For equations with powers, write every term with the same base first.
  • For fractional powers, do the root first. It keeps the numbers small.

Worksheet

Calculator: not allowed for Q1-Q6. Total: 25 marks. Show all working.

  1. Simplify √50 + √18. Give your answer in the form a√b. (2)
  2. Rationalise the denominator of 6/√3. (2)
  3. Expand and simplify (3 + √5)(3 − √5). (2)
  4. Show that 4/(2 + √3) can be written as 8 − 4√3. (3)
  5. Work out the value of
    (a) 64^(−2/3) (2)
    (b) (81/16)^(3/4) (2)
  6. Solve 4ˣ = 8^(x−1). (3)
  7. Show that (√12 + √3)² is an integer. (3)
  8. A rectangle has area 24 cm² and width √6 cm. Find the length in the form a√b. (3)
  9. Challenge: Given that (a + √b)² = 11 + 6√2 where a and b are positive integers, find a and b. (3)

Try the worksheet first, then check your work here.

  1. √50 = 5√2 and √18 = 3√2, so the answer is 8√2. (M1 simplify one, A1)
  2. 6√3/3 = 2√3. (M1 multiply by √3/√3, A1)
  3. 9 − 5 = 4. (M1 expand, A1)
  4. 4(2 − √3) / ((2 + √3)(2 − √3)) = 4(2 − √3)/(4 − 3) = 8 − 4√3. (M1 conjugate, M1 denominator = 1, A1)
  5. (a) 64^(1/3) = 4, 4² = 16, so 1/16. (M1, A1)
    (b) (81/16)^(1/4) = 3/2, then (3/2)³ = 27/8. (M1, A1)
  6. 2^(2x) = 2^(3x − 3), so 2x = 3x − 3 and x = 3. (M1 same base, M1 equate, A1)
  7. (√12 + √3)² = 12 + 2√36 + 3 = 12 + 12 + 3 = 27, an integer. (M1 expand, M1 √36 = 6, A1)
  8. Length = 24/√6 = 24√6/6 = 4√6 cm. (M1, M1 rationalise, A1)
  9. Expanding gives a² + b + 2a√b. Matching the surd part: 2a√b = 6√2. Try a = 3: 6√b = 6√2, so b = 2. Check the rational part: 9 + 2 = 11 ✓. a = 3, b = 2. (M1, M1, A1)
